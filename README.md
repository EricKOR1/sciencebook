# 한 권으로 잇는 과학

**중학교 1학년부터 대학 일반 과학까지 한 권으로 엮은 과학 학습 교재** (중·고등학교는 2022 개정 교육과정 기준)

> 학년이 올라가도 같은 개념이 어떻게 이어지고 깊어지는지 한눈에 따라갈 수 있도록, 140개 단원을 하나의 책(웹사이트)으로 묶었다.

## 바로 보기

**👉 https://erickor1.github.io/sciencebook/**

(처음 한 번은 저장소 **Settings → Pages** 에서 Source를 *Deploy from a branch*, 폴더를 `/docs` 로 지정해야 열린다.)

인터넷 없이 보려면 [`download/sciencebook-web.zip`](download/sciencebook-web.zip)을 받아 압축을 풀고 `index.html`을 연다.

## 이 책의 특징

| 특징 | 내용 |
|---|---|
| 🎯 **교육과정에 맞춤** | 중·고등학교 단원은 교육부 고시 제2022-33호 [별책 9] 「과학과 교육과정」의 성취기준을 원문 그대로 싣고 해설의 범위를 지켰다. 대학 일반 과학 단원은 대학 1학년 과정에서 널리 쓰이는 교재들의 공통 목차를 참고해 범위를 정하고 내용은 새로 썼다 |
| 🔗 **개념 연계** | 단원마다 "먼저 배운 내용 → 지금 → 이어지는 내용"을 바로 오갈 수 있고, 전체 흐름은 개념 연계 지도에서 본다 |
| 🧱 **6단계 학습 흐름** | 이전 학습 다시 보기 → 기초 다지기 → 핵심 개념 → 오개념 바로잡기 → 다음 단계로 한 걸음 더 → 생활·산업·진로 연결 |
| 🖼️ **그림 1005개** | 위치·구조·과정을 글만으로 떠올리기 어려운 곳마다 그림을 넣었다. 기단·해류·판의 경계·태풍 경로 같은 지도는 실제 해안선 위에 그렸다 |
| 🕹️ **2D·3D 시뮬레이션 193개** | 이해하기 어려운 개념은 직접 움직여 보는 시뮬레이션으로 익힌다(분자·결정 구조, DNA, 오비탈, 천체의 운동 등 21개는 돌려 보는 입체 모형) |
| ✔ **바로 확인 1033곳** | 핵심 개념의 소절이 끝날 때마다 방금 읽은 내용을 점검하는 쉬운 문항 2~4개(모두 3700여 문항) |
| ✅ **탐구 활동과 난이도별 확인 문제** | 모든 단원에 탐구 활동과 정답·해설이 달린 확인 문제 — 기본(★) → 응용·융합(★★) → 실력 다지기(★★) → 도전(★★★). 한눈에 정리와 핵심 용어 표 |
| 📌 **이어서 학습하기** | 읽던 위치와 읽은 정도, 완료한 단원을 기기별로 기억해 다음에 이어서 볼 수 있다(기록은 그 기기의 브라우저에만 저장) |

### 웹사이트 다시 만들기

원고를 고친 뒤 아래 명령을 실행하면 `docs/`가 새로 만들어진다.

```bash
cd tools
npm install        # 처음 한 번
node build.mjs     # 전체 다시 만들기 (node build.mjs m1-03 처럼 단원 id를 주면 그 단원만)
python3 authoring/check_lesson.py   # 원고 형식 점검
```
