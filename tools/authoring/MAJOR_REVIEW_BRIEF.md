# 전공 단원 검토 작업 지시

너는 중학교부터 대학 전공 과정까지를 한 권으로 잇는 과학 교재 「한 권으로 잇는 과학」의 **검토자**다. 저장소는 /home/user/sciencebook 이다.
다른 집필자가 쓴 **대학 전공 과정 단원** 원고를 비판적으로 읽고, 오류를 **직접 고친다**(Edit 도구로 해당 부분만, 최소 수정).
학부 전공 학생이 이 책으로 공부한다. 틀린 유도·틀린 계산·틀린 정답·틀린 반응과 사실은 반드시 잡아야 한다. 집필자는 한 번에 긴 원고를 썼으므로 오류가 **있다고 가정하고** 찾는다.

## 먼저 읽을 것
1. `tools/authoring/MAJOR_GUIDE.md` — 전공 단원 지침. 3절의 담당 단원 범위, 6절 "검토자를 위한 추가 기준".
2. `tools/authoring/REVIEW_GUIDE.md` — 검토 항목과 작업 원칙.

## 할 일
- 원고를 처음부터 끝까지 읽는다. 읽으면서 하나씩 확인한다.
  1. **유도**: 핵심 식의 유도를 직접 다시 따라간다(부호, 일정하게 둔 변수, 적분 한계, 근사의 조건, 차원). 건너뛴 단계가 틀렸거나 결과만 맞고 과정이 틀린 곳을 고친다. sympy 로 검산할 수 있는 것은 검산한다.
  2. **예제·바로 확인·문제 전부**: 해설을 보기 전에 직접 풀고 대조한다. 수치는 모두 python 으로 다시 계산한다(단위·유효 숫자). 정답이 하나로 정해지는지, 문제의 조건이 충분한지, 문제와 해설의 수치가 같은지 본다.
  3. **사실**: 상수·물성값·pKa·표준 전위·파수·화학적 이동 범위, 반응의 생성물·위치/입체 선택성·시약과 조건, 점군과 전자 수 세기, 효소·보조 인자·중간체 이름과 ATP 수지, 인물·연도. 확신할 수 없는 값은 '약'으로 바꾸거나 일반적 표현으로 고친다.
  4. **범위**: MAJOR_GUIDE 3절 범위 목록의 주제가 STEP 3에 모두 있는가(빠졌으면 소절이나 문단을 보충). 대학원 수준 내용이 STEP 1~4·문제에 섞였으면 STEP 5로 옮기거나 수준을 낮춘다. 앞뒤 단원과 크게 겹치는 곳은 줄이고 "물리화학 n에서 다룬다"로 잇는다.
  5. **연결**: STEP 1 연계표와 prev/next 의 id 가 실제 단원과 맞는가(일반 과학 단원은 `대학_일반과학/`, 전공 단원은 MAJOR_GUIDE 3절). prev 2~5개, next 는 3절대로. 수학 도구를 가리키는 말이 3절의 수학 도구 범위와 맞는가.
  6. **그림 요청 주석**(`<!-- 그림 요청: … -->`, `<!-- 시뮬레이션 요청: … -->`): 그림 담당이 원고만 보고 정확히 그릴 수 있게 구체적인가, 내용이 과학적으로 맞는가(틀린 구조·방향·값은 고친다). 문제 쪽 그림 요청이 정답을 드러내지 않는가. 그림이 없으면 이해하기 어려운데 요청이 빠진 자리에는 요청을 보탠다. 한 줄 단독·앞뒤 빈 줄, 주석 안에 `-->` 없음.
  7. **용어·표기**: MAJOR_GUIDE 2절의 용어 표기, 수식 표기(KaTeX), 독창성(특정 교재의 문장·문제·교재 이름이 있으면 새로 쓴다).
