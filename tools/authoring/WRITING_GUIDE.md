# 집필 지침 — 「한 권으로 잇는 과학」

중학교 1학년부터 고등학교 진로 선택 과목까지(2022 개정 교육과정)를 한 권으로 잇는 교재의 단원 원고를 쓰는 기준이다.
이 책의 가장 큰 목표는 **개념이 학년을 따라 어떻게 이어지고 깊어지는지**를 학생이 따라갈 수 있게 하는 것이다.

## 0. 먼저 읽을 것
1. 견본 단원(이 구조·밀도·말투를 따른다): `통합과학1/3단원_시스템과_상호작용/3-4_운동량과_충격량.md`
   (견본은 성취기준 1개짜리 단원이다. 너는 **영역(단원) 전체**를 한 파일로 쓰므로 STEP 3이 더 길고 소절이 더 많다.)
2. 전체 단원 목록(id·제목·파일 경로): `tools/authoring/LESSONS.md`
3. 교육과정 원문: `tools/authoring/curriculum/` — 중학교 `middle.txt`, 통합과학 `integrated.txt`, 선택과목은 `phy.txt` 등 과목별 파일
   (성취기준, 성취기준 해설, 적용 시 고려 사항, 탐구 활동이 들어 있다)

## 1. 한 파일 = 교육과정의 한 영역(단원)
- 파일 경로와 id는 LESSONS.md에 적힌 그대로. 폴더가 없으면 만든다.
- 그 영역의 **성취기준을 빠짐없이** 다룬다. 성취기준 문구는 **원문 그대로** 인용(줄바꿈만 정리)하고, 코드를 지어내지 않는다.
- 성취기준 해설의 "다루지 않는다", "~수준에서 다룬다", "정성적으로" 같은 **범위 제한을 반드시 지킨다.** 범위를 넘는 내용은 STEP 5에만 쓴다.
- 분량: 중학교 단원 500~750줄, 고등학교 선택과목 단원 650~950줄(성취기준 수에 비례). STEP 3(핵심 개념)이 가장 두껍다.

## 2. 파일 구조 (헤딩 이름과 순서를 그대로)
```
# {표시 번호}. {제목} — {부제}                ← 예: "# 중1-5. 힘의 작용 — 밀고 당기는 모든 것의 규칙", "# 물리학 1. 힘과 에너지 — …"
<!-- prev: m1-05, 3-3 -->                      ← 이 단원보다 먼저 배우는 관련 단원 id (쉼표로 구분, 없으면 줄 생략)
<!-- next: phy-1, mech-1 -->                   ← 이 단원에서 이어지는 관련 단원 id

> [!NOTE]
> **성취기준**
> - **[9과05-01]** 원문…
> - **[9과05-02]** 원문…                       ← 이 영역의 모든 성취기준

**학습 목표** (4~6개 번호 목록)

**이 단원의 학습 사다리** (표: STEP 1~6 한 줄 요약)

---

## 🗺️ 단원 들어가기                ← 호기심을 끄는 질문·장면 + mermaid 개념 지도 1개
## STEP 1. 🔙 이전 학습 다시 보기      ← 연계표(이전 단원·성취기준 | 그때 배운 것 | 이 단원에서 확장되는 것) + 준비 운동(사전 진단 3~4문항, 정답은 <details>)
## STEP 2. 🧱 기초 다지기            ← 이 단원 이해에 필요한 디딤돌 개념·수학 도구. 비유 적극 사용
## STEP 3. 📘 핵심 개념              ← 성취기준마다 소절 1개 이상: "### ① 소절 제목" … 각 소절에 설명 + 표 + 예제(풀이 포함) + TIP
## STEP 4. ⚠️ 오개념 바로잡기         ← 표(흔한 오개념 | 올바른 개념 | 왜 그럴까?) 5~7행
## STEP 5. 🎓 다음 단계로 한 걸음 더    ← [!CAUTION] 상자(범위 밖·평가 대상 아님) → 다음 학년·과목 연결표 → 같은 개념이 다음 단계에서 어떻게 확장되는지 맛보기 → 비교표(지금 vs 다음 단계)
## STEP 6. 🏭 생활·산업·진로 연결      ← 실제 사례 2~4개(원리 → 어디에 쓰이나) + 관련 진로·학과 표
## 🔬 탐구 활동                    ← 교육과정 <탐구 활동> 기반 1~2개. 목표/준비물/과정/결과 기록 표/생각해 보기/안전 수칙
## ✅ 개념 확인 문제                ← "### 기본" 4~5문항, "### 응용" 3~4문항, "### 융합·서술형" 2문항. 문항은 "**1.** …" 형식, 문항 바로 아래 <details>에 정답과 해설
## 📝 한눈에 정리                  ← "### 핵심 요약"(6~9줄 목록) + "### 핵심 용어"(표: | 용어 | 뜻 |, 8~12개) + "### 다음 단원으로"(연결 문장)
```

### 개념 연결(prev / next)이 이 책의 핵심이다
- `prev`: 이 단원을 배우기 전에 알아야 하는, **이 책 안의** 앞 단계 단원 id. `next`: 이 개념이 이어지는 뒤 단계 단원 id. LESSONS.md의 id만 쓴다.
- 교육과정 "성취기준 적용 시 고려 사항"의 연계 문장("…와 연계된다")을 근거로 고르고, 관련이 뚜렷한 것만 2~6개.
- **STEP 1의 연계표**: 이전 단원을 구체적으로 가리킨다(예: "중1 「힘의 작용」 [9과05-03]", "통합과학1 「중력과 운동」"). 중학교 1학년 단원은 초등학교에서 배운 내용(교육과정 연계 문장에 나온 초등 단원명)을 쓴다.
- **STEP 5**: 다음 단계 단원을 구체적으로 가리킨다. 중학교 단원은 → 통합과학·선택과목, 통합과학·일반 선택은 → 진로 선택, 진로 선택은 → 대학 전공 과목.
- 본문에서 다른 단원을 언급할 때는 「단원 제목」처럼 낫표로 쓴다(링크는 빌드가 자동으로 '개념 연결' 상자에 만든다).
- **예시와 비유**: 소절마다 생활 속 예시를 1개 이상. 새 용어는 처음 나올 때 **굵게** + (영어).

## 3. 독자에 맞춘 수준
- 중학교 단원: 중학생이 혼자 읽을 수 있게. 짧은 문장, 쉬운 말, 수식은 교육과정이 요구하는 것만(비례 관계 중심), 계산은 간단한 수로.
- 고등학교 일반 선택: 통합과학을 마친 고2. 정량적 관계와 그래프 해석을 본격적으로.
- 고등학교 진로 선택: 해당 일반 선택(물리학·화학·생명과학·지구과학)을 배운 고2~3. 원리의 유도와 응용, 대학 연결.
- 문체는 교과서체("~이다", "~해 보자"). 

## 4. 표기 규칙
- 수식: GitHub 수학 문법. 인라인 `$p = mv$`, 블록은 앞뒤 빈 줄을 두고 `$$ … $$`. 단위는 `\mathrm{kg\cdot m/s}`. 표 셀 안에는 단순한 수식만(세로선 `|` 금지 → `\lvert x \rvert`).
- 화학식: 본문은 `$\mathrm{H_2O}$`, `$\mathrm{Na^+}$` 형식.
- mermaid: `flowchart`만. **모든 노드 라벨을 큰따옴표로**: `A["힘<br/>알짜힘"] --> B["가속도"]`. 화살표 라벨은 `-->|"라벨"|`. 라벨 안에 큰따옴표·세미콜론 금지.
- 상자: `> [!NOTE]` 참고, `> [!TIP]` 비유·요령, `> [!IMPORTANT]` 핵심, `> [!WARNING]` 주의·안전, `> [!CAUTION]` 범위 밖 심화.
- 정답 접기(빈 줄 필수):
  ```
  <details>
  <summary>정답 및 해설</summary>

  **정답** …

  해설 …

  </details>
  ```
- 그림 설명이 필요한 곳은 글과 표로 충분히 풀어 쓴다(그림·시뮬레이션은 다음 단계에서 다른 담당자가 넣는다). 이미지 링크를 넣지 않는다.
- 수치·상수·연도·기관명은 확실한 것만. 불확실하면 "약"을 붙이거나 일반적 표현으로. 특정 기업 홍보 금지.

## 5. 제출 전 점검 (반드시)
1. `python3 tools/authoring/check_lesson.py <네 파일들>` → 모두 OK
2. 예제·문제의 계산을 python으로 다시 계산(단위 포함). 정답이 유일하고 해설과 일치하는지 확인.
3. 성취기준 원문·범위 제한을 교육과정 파일과 다시 대조.
4. git 커밋·푸시는 하지 않는다. 담당 파일 외에는 수정하지 않는다.

## 6. 최종 보고 (간결하게)
1. 만든 파일과 줄 수
2. 단원별 prev / next 로 고른 id와 근거 한 줄
3. 그림·시뮬레이션 제안: 단원별로 "글만으로 이해하기 어려운 개념" 2~4개와, 그중 직접 조작해 보면 좋은 것(2D/3D) 1~2개
4. 확신이 부족해 '약'으로 쓰거나 뺀 사실, 교육과정 범위 판단이 애매했던 곳
