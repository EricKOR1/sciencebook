# 대학 단원 그림·시뮬레이션 작업 지시

너는 중학교부터 대학 1학년까지를 한 권으로 잇는 과학 교재 웹사이트 「한 권으로 잇는 과학」의 **그림·시뮬레이션 담당**이다. 저장소는 /home/user/sciencebook 이다.
담당 단원 원고에 정적 그림(SVG)과 직접 조작하는 시뮬레이션(JS)을 만들어 넣는다.

## 먼저 읽을 것 (순서대로)
1. `tools/authoring/VISUALS_GUIDE.md` — 제작 지침 전체(표식, SVG 규칙, 시뮬레이션 API, 확인 방법, 하지 말 것, 보고 형식). 거기 적힌 견본 파일들도 읽는다.
2. `tools/authoring/UNIV_GUIDE.md` 7절 — 대학 단원에서 달라지는 점.
3. 담당 단원 원고 전체.
4. 이미 있는 시뮬레이션: `ls docs/assets/js/sims/` (이름으로 내용을 짐작하고, 겹칠 만한 것은 파일 머리의 title·caption 을 확인한다).

## 만들 것
- 단원마다 **그림 3개 + 새 시뮬레이션 1~2개**. 시뮬레이션 이름은 반드시 `u-`로 시작한다.
- 고등학교 단원에 이미 있는 시뮬레이션과 **같은 내용을 다시 만들지 않는다.** 대학 수준에서 새로 보이는 것(적분·미분의 의미, 매개변수 의존성, 정량 그래프, 벡터장, 오비탈, 메커니즘, 모형 등)을 고른다.
  기존 시뮬레이션이 그대로 도움이 되면 원고에 그 표식을 한 번 더 넣어 재사용해도 된다(개수에 넣지 않는다).
- 작업 지시에 적힌 집필자의 제안은 참고일 뿐이다. 원고를 읽고 더 알맞은 것이 있으면 같은 개수 안에서 바꿔도 된다.
- 원고의 STEP 5(전공 맛보기)에만 있는 내용은 시뮬레이션으로 만들지 않는다.

## 지킬 것
- 원고에는 표식 줄만 넣는다(한 줄 단독, 앞뒤 빈 줄). 다른 글은 고치지 않는다. 명백한 과학 오류를 보면 고치지 말고 보고에 적는다.
- `tools/build.mjs`, `docs/assets/js/book.js`, `docs/assets/book.css`, `tools/screenshot.mjs`, `tools/book.json` 과 다른 담당의 파일은 수정하지 않는다.
  전체 빌드(인자 없는 build.mjs)와 git 커밋·푸시를 하지 않는다.
- 확인: `cd tools && node build.mjs <담당 id들>` 후 `screenshot.mjs` 로 밝은 화면 1280, 어두운 화면 390 을 찍어 png 를 직접 본다. 버튼·슬라이더를 조작한 뒤 상태도 확인한다.
- 확인용 파일은 scratchpad 안의 **네 전용 폴더**(작업 지시에 적힌 이름)에만 둔다. 저장소 안이나 다른 곳에 확인용 파일을 만들지 않는다.
  scratchpad: `/tmp/claude-0/-home-user-sciencebook/96b7e817-0e5e-5324-8416-180ac4e267af/scratchpad/` (전용 폴더가 없으면 mkdir -p)
- 휴대폰에서 캔버스 위를 쓸면 쪽이 넘어가도록 기본 설정되어 있다. 캔버스에서 끌어서 조작하는 시뮬레이션을 만들 때만 그 캔버스에
  `canvas.style.touchAction = 'none'`(자유롭게 끌기) 또는 `'pan-y'`(좌우로만 끌기)를 건다.
