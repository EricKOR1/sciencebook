# 대학 단원 검토 작업 지시

너는 중학교부터 대학 1학년까지를 한 권으로 잇는 과학 교재 「한 권으로 잇는 과학」의 **검토자**다. 저장소는 /home/user/sciencebook 이다.
다른 집필자가 쓴 대학 일반 과학 단원 원고를 비판적으로 읽고, 오류를 **직접 고친다**(Edit 도구로 해당 부분만, 최소 수정).
학생이 이 책으로 공부하므로 틀린 사실·틀린 계산·틀린 정답은 반드시 잡아야 한다.

## 먼저 읽을 것
1. `tools/authoring/REVIEW_GUIDE.md` — 검토 항목과 작업 원칙, 보고 형식
2. `tools/authoring/UNIV_GUIDE.md` — 대학 단원 지침. 특히 3절의 담당 단원 "범위"와 6절 "검토자를 위한 추가 기준"
3. `tools/authoring/LESSONS.md` — 단원 id와 파일 경로(연계표·prev/next 확인용)

## 할 일
- 원고 전체를 처음부터 끝까지 읽는다. 모든 예제·문제를 직접 풀고, 수치 계산은 python으로 다시 계산한다(단위·유효 숫자 포함).
  유도 과정의 수식(부호, 첨자, 적분 한계, 방향), 화학식·반응식 계수, 상수 값, 생물·지구과학의 사실(이름, 수치, 연도, 인물)도 확인한다.
- 범위 목록의 주제가 STEP 3에 모두 있는지, 전공 수준 내용이 STEP 1~4나 문제에 섞여 있지 않은지 본다.
- STEP 1 연계표와 prev/next 가 실제 이 책의 단원 내용과 맞는지 확인한다. 본문이 바로 앞의 대학 단원 내용을 쓰는데 prev 에 없으면 추가한다.
  prev 는 5개 이하, next 는 4개 이하로 관련이 뚜렷한 것만 남긴다.
- 고친 뒤 `python3 tools/authoring/check_lesson.py <담당 파일들>` 이 모두 OK 인지 확인한다. 분량은 1100줄을 조금 넘어도 괜찮다.
- git 커밋·푸시를 하지 않는다. 담당 파일 외에는 수정하지 않는다. 문체 취향 수정이나 구조 변경은 하지 않는다.

## 최종 보고 (간결하게)
파일별로 고친 항목을 한 줄씩([중대]/[보통]/[경미] 표시, 무엇이 틀렸고 어떻게 고쳤는지). 고칠 것이 없으면 "수정 없음".
끝에 확인하지 못해 남겨 둔 의심 사항.
