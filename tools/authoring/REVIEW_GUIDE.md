# 검토 지침 — 「한 권으로 잇는 과학」

다른 집필자가 쓴 단원 원고를 비판적으로 읽고 **오류를 직접 고치는** 검토자를 위한 기준이다.
학생이 이 책으로 공부하므로 틀린 사실·틀린 계산·틀린 정답은 반드시 잡는다.

## 참고 자료
- 집필 지침(구조·표기·범위 원칙): `tools/authoring/WRITING_GUIDE.md`
- 교육과정 원문: `tools/authoring/curriculum/` (중학교 `middle.txt`, 통합과학 `integrated.txt`, 선택과목 과목별 파일)
- 단원 목록: `tools/authoring/LESSONS.md`

## 검토 항목 (우선순위 순)
1. **과학적 사실** — 정의, 원리 설명, 수치, 단위, 연도, 기관명, 화학식·반응식 계수, 유전 암호, 천체 자료 등. 확실히 틀린 것은 고치고, 확신할 수 없는 구체 수치는 '약'을 붙이거나 일반적 표현으로 바꾼다.
2. **계산** — 모든 예제·문제의 계산을 python으로 다시 계산한다(단위 포함).
3. **정답·해설** — 모든 문항을 직접 풀어 본다. 정답이 유일한지, 해설이 정답과 일치하는지, '모두 고르시오' 문항은 보기 하나하나.
4. **교육과정 범위** — STEP 1~4, 탐구 활동, 확인 문제가 성취기준 해설의 범위 제한("다루지 않는다", "정성적으로", "~수준에서")을 넘지 않는지. 넘으면 STEP 5로 옮기거나 범위 안 표현·문제로 바꾼다. 빠진 성취기준 내용이 있으면 보충한다.
5. **수준** — 중학교 단원이 중학생에게 너무 어렵지 않은지(범위 밖 용어·수식), 선택과목 단원이 그 과목 수준의 정량적 내용을 충분히 담았는지.
6. **개념 연결** — `prev`/`next` id가 타당한지(관련이 뚜렷한 것만), STEP 1 연계표와 STEP 5가 실제 그 단원의 내용과 맞는지(LESSONS.md와 교육과정으로 확인). 틀리면 고친다.
7. **오해를 부르는 비유·표현**, **실험 안전 수칙 누락**.
8. **형식** — 고친 뒤에도 `python3 tools/authoring/check_lesson.py <파일들>` 이 모두 OK.

## 작업 원칙
- **최소 수정**: 맞는 내용은 건드리지 않는다. 문체 취향 수정, 구조·헤딩 변경은 하지 않는다. Edit 도구로 해당 부분만 고친다.
- git 커밋·푸시는 하지 않는다. 담당 파일 외에는 수정하지 않는다. `tools/` 아래 파일을 고치지 않는다.
